# Revenue Dynamics Advisors — Website (GitHub Pages)

Pages included: Home, About, Services, Startup Solutions, Calculators, Blog/Articles, News & Updates, Write for Us, Contact.
Calculators: Income Tax, GST, EMI (client-side JS).

## Deploy on GitHub Pages
1) Create a new GitHub repository and upload all files (drag & drop in the GitHub web UI).
2) Repo → Settings → Pages:
   - Source: Deploy from a branch
   - Branch: main, Folder: / (root)
   - Save, wait ~1–2 minutes.
3) Optional custom domain: Settings → Pages → Custom domain.
4) Blog posts live in `_posts` as Markdown files. Use PRs + branch protection for approvals.
