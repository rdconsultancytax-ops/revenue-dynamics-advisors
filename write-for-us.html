Option B — GitHub (faster for tech-savvy authors)

  1. Open our repository: https://github.com/<your-username>/revenue-dynamics-advisors
  2. Click Fork (top-right).
  3. Inside your fork, open the _posts folder → Add file → Create new file.
  4. Name it like YYYY-MM-DD-your-title.md, then paste this template:
---
title: "Your Article Title"
date: 2025-10-02
author: "Your Name"
---
